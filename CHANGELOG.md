# Changelog

All notable changes to Health Analyzer will be documented in this file.

This project currently follows an early-stage "initial implementation" cadence.
Semantic versioning will be adopted once public release artifacts are published.

## 1.0.1-alpha - 2026-06-07

- Refined the primary Dashboard, Activity, and AI Coach experiences with a more
  focused, experience-first layout.
- Updated the Android launcher icons and in-app brand treatment to use the
  JalaJO-inspired green identity.
- Fixed several mobile layout risks, including cramped route tools and
  segmented controls in settings screens.
- Polished open-source README and contribution guidance for safer public
  collaboration.

## 1.0.0-alpha - 2026-06-05

- Built the first super-app roadmap implementation for personal fitness,
  wearable health summaries, activity recording, AI coach, offline-first local
  storage, Turso sync, Koyeb community gateway, and optional external AI agent
  setup.
- Added Apache-2.0 open-source project files.
- Added EOX Sentinel-2 Cloudless 2017 as the default free/open online satellite
  source.
- Added regional PMTiles offline map infrastructure.
